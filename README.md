## SupportMe

SupportMe is a dummy dashboard project created as a part of the Shadcn UI & NextJS course.

Tech stack used:

- `shadcn/ui`
- `NextJS`
- `Tailwind`

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
